1. Онбординг пустого магазина. Когда владелец входит впервые, нужен понятный сценарий:
```
1. Заполните информацию о магазине
2. Загрузите логотип
3. Добавьте первый товар
4. Скопируйте ссылку
```

2. Заглушки для пустых состояний. Нужны экраны:
```
нет товаров;
нет изображений;
магазин еще не заполнен;
подписка истекла;
магазин архивирован;
AI недоступен.
```

3. Копирование публичной ссылки одной кнопкой.
```
кнопка "Копировать";
уведомление "Ссылка скопирована".
```

4. Базовая аналитика магазина. Для владельца:

```
количество товаров;
просмотры магазина;
просмотры товаров.
```

5. Подтверждение опасных действий. Иначе ошибки пользователей неизбежны. Нужны модалки:

```
удалить товар;
архивировать магазин;
удалить владельца;
сменить пароль.
```

6. QR-код публичной витрины. Рядом с кнопкой скопировать ссылку также должна быть кнопка поделиться QR кодом (в статус ватсап, или пользователю ватсап\телеграм)

7. Черновик автосохранения. Если владелец случайно закрыл вкладку, данные не теряются. Даже локальное сохранение в localStorage уже достаточно для MVP.
