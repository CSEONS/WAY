# Domain Model

Документ описывает предметную область существующего проекта цифровой витрины.

## User

### Назначение

Пользователь системы. Может быть администратором или владельцем магазина.

### Атрибуты

- id
- name
- email
- phone
- passwordHash
- role
- createdAt
- updatedAt

### Связи

- User → Store
- Один владелец (`OWNER`) может владеть несколькими магазинами.
- Администратор (`ADMIN`) не связан с магазином напрямую, но управляет владельцами и магазинами.

### Правила

- Роль должна быть `ADMIN` или `OWNER`.
- Для владельца пользователя сохраняется пароль как хеш.
- Владелец может иметь несколько магазинов.
- Администратор может просматривать и изменять владельцев и магазины.

## Store

### Назначение

Торговый магазин, представляющий собой публичную витрину одежды.

### Атрибуты

- id
- ownerId
- name
- slug
- description
- address
- phone
- whatsapp
- telegram
- logoUrl
- coverUrl
- isActive
- aiFormEnabled
- subscriptionEndsAt
- createdAt
- updatedAt

### Связи

- Store → User (owner)
- Store → Product
- Store → AnalyticsEvent

### Правила

- Магазин принадлежит одному владельцу.
- Каждый магазин имеет уникальный `slug`.
- Магазин доступен в публичной витрине только если `isActive` равно 1 и `subscriptionEndsAt` не истекла (или не задана).
- `aiFormEnabled` управляет доступностью AI-заполнения товара для владельца.
- Магазин может быть отключён или восстановлен.

## Product

### Назначение

Предмет одежды, который владелец размещает в витрине магазина.

### Атрибуты

- id
- storeId
- title
- description
- price
- priceText
- category
- status
- isVisible
- createdAt
- updatedAt

### Связи

- Product → Store
- Product → ProductImage
- Product → ProductSize
- Product → ProductColor
- Product → ProductVariant

### Правила

- Продукт принадлежит одному магазину.
- У продукта должно быть название.
- Статус продукта может быть `AVAILABLE`, `NOT_AVAILABLE` или `CHECK_IN_STORE`.
- `isVisible` управляет включением продукта в публичный список.
- Публичная витрина показывает только продукты с `isVisible = 1`.
- Продукт может иметь категории только как текстовую метку, в системе нет отдельной сущности категории.

## ProductImage

### Назначение

Изображение товара.

### Атрибуты

- id
- productId
- url
- sortOrder
- createdAt

### Связи

- ProductImage → Product

### Правила

- Изображение привязано к одному продукту.
- Порядок отображения задаётся `sortOrder`.
- Первое изображение используется как превью.

## ProductSize

### Назначение

Размер товара.

### Атрибуты

- id
- productId
- value

### Связи

- ProductSize → Product

### Правила

- Размер привязан к конкретному продукту.
- Размеры представлены текстовыми значениями.
- Размеры синхронизируются с вариантами продукта.

## ProductColor

### Назначение

Цвет товара.

### Атрибуты

- id
- productId
- name
- hex

### Связи

- ProductColor → Product

### Правила

- Цвет привязан к конкретному продукту.
- Цвет имеет имя и необязательное HEX-значение.
- Цвета синхронизируются с вариантами продукта.

## ProductVariant

### Назначение

Комбинация цвета, размера и цены для товара.

### Атрибуты

- id
- productId
- colorName
- colorHex
- size
- price

### Связи

- ProductVariant → Product

### Правила

- Вариант привязан к одному продукту.
- Вариант содержит цвет, размер и цену.
- Если для продукта определены варианты, они используются для формирования списка доступных сочетаний.

## Category

### Назначение

Классификация товара в магазине.

### Атрибуты

- category (текстовая метка на продукте)

### Связи

- Category → Product

### Правила

- В проекте категория реализована как строковый атрибут продукта.
- Отдельной сущности `Category` в базе данных нет.

## Subscription

### Назначение

Состояние оплаты магазина и доступа витрины.

### Атрибуты

- isActive (флаг активности магазина)
- subscriptionEndsAt (дата окончания подписки)

### Связи

- Subscription → Store

### Правила

- Подписка хранится в рамках магазина, отдельной таблицы нет.
- Магазин считается доступным, если он активен и дата подписки не истекла или отсутствует.
- Если подписка истекла или магазин отключен, публичный доступ запрещён.

## AnalyticsEvent

### Назначение

Фиксация просмотров витрины и товаров для аналитики.

### Атрибуты

- id
- storeId
- productId
- type
- createdAt

### Связи

- AnalyticsEvent → Store
- AnalyticsEvent → Product (опционально)

### Правила

- Тип может быть `STORE_VIEW` или `PRODUCT_VIEW`.
- Запись создаётся при просмотре магазина или товара.
- Аналитика агрегируется по количеству событий.

## AiDraft

### Назначение

Предложение значений товара на основе AI-помощника.

### Атрибуты

- title
- description
- price
- priceText
- category
- status
- isVisible
- sizes
- colors
- variants

### Связи

- AiDraft не сохраняется в базе как отдельная сущность.
- AiDraft используется для заполнения формы Product.

### Правила

- AiDraft создаётся на лету из текстового описания или голосового файла.
- AiDraft служит рекомендацией, которую пользователь может изменить.
- AiDraft не принимает финальных решений за владельца.

## Термины

### Витрина

Публичный канал отображения товаров магазина без оформления покупки.

### Магазин

Представление торговой точки владельца с товарами, контактами и настройками доступа.

### Владелец

Пользователь с ролью `OWNER`, который управляет магазином и товарами.

### AI Draft

Временный набор предложенных данных товара, сгенерированный AI-помощником для заполнения формы.

### Подписка

Статус доступа магазина к публичной витрине, основанный на флаге активности и дате окончания подписки.
