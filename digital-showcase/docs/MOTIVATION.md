# Мотивация разработки сайта

## Основная цель

Создать простой сервис цифровой витрины для небольших магазинов одежды, который позволит покупателям заранее ознакомиться с ассортиментом магазина, а владельцам — быстро публиковать новые товары.

---

## Причины разработки

- Сервис разрабатывается как коммерческий проект с целью получения прибыли.
- Первые клиенты будут оплачивать использование сервиса наличными.
- Проект должен масштабироваться на другие магазины после успешного запуска.

---

## Личная мотивация

Первым пользователем сервиса станет моя мама.

Она продаёт одежду, но ей сложно пользоваться современными технологиями и самостоятельно заполнять карточки товаров. Поэтому сервис разрабатывается максимально простым и понятным.

---

## Использование искусственного интеллекта

ИИ используется только как помощник.

Его основная задача:

- заполнение данных в форме товара на основе изображений товара;
- принятие на вход текстового описания товара или голосового описания товара;
- при голосовом описании: отправка голосового файла через API к языковой модели, которая сама распознаёт текст и генерирует необходимые поля;
- автоматическое создание названия и описания товара;
- предложение цветов, размеров и других характеристик.

ИИ не принимает никаких решений за пользователя и не управляет магазином.

---

## Роли пользователей

### Администратор

- управляет системой;
- создаёт и удаляет магазины;
- управляет тарифами;
- контролирует работу сервиса.

### Владелец магазина

- публикует товары;
- редактирует товары;
- просматривает статистику;
- управляет своим магазином.

### Пользователь

- просматривает товары;
- добавляет товары в избранное;
- ищет интересующие товары.

---

## Основные принципы проекта

- Максимально простой интерфейс.
- Возможность пользоваться сервисом без технических знаний.
- Минимальное количество действий для публикации товара.
- Основной сценарий — загрузить фотографии, при необходимости продиктовать описание и опубликовать товар.
- Сервис является электронной витриной, а не интернет-магазином.

---

## Монетизация

Источник дохода — ежемесячная подписка владельцев магазинов.

При неоплаченной подписке магазин становится недоступен до продления оплаты.
