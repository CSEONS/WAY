Полностью переработай UI и UX проекта в соответствии с Apple Human Interface Guidelines (HIG), адаптировав их для современного веб-приложения. Используй подход Mobile First: сначала спроектируй интерфейс для смартфонов, а затем обеспечь его корректную адаптацию для планшетов и десктопов. Интерфейс должен ощущаться как нативное приложение Apple, а не как обычный сайт.

Приведи все страницы, компоненты и пользовательские сценарии к единому стилю HIG. Используй большие заголовки (Large Titles), SF Symbols (или их аналоги), карточный интерфейс, качественную типографику, правильную визуальную иерархию, крупные области нажатия, нативные элементы управления, плавные анимации и современные эффекты (например, blur и glassmorphism там, где это уместно).

Переработай не только внешний вид, но и UX: упрости пользовательские сценарии, сократи количество действий для выполнения основных задач, убери лишние элементы, сделай навигацию очевидной и последовательной. Особое внимание удели удобству использования одной рукой на мобильных устройствах.

Не изменяй бизнес-логику, API и функциональность проекта. Измени только дизайн, компоновку, компоненты и пользовательский опыт. Все новые компоненты должны быть переиспользуемыми, адаптивными и выполненными в едином дизайн-языке.
