1. Нужно показывать подскзаки "плейсхолдер" в поля куда нужно ввести данные для ватсап телеграм и прочее. К примеру для ватсап номер `+79280123456` для телеграм никнейм `@Name`и т. д.

2. При массовом создании товароа нужно чтобы если есть хотябы немного похожие товары то они добавлялись в картинки 1 товара. Типа если есть джинсы нескольких цветов, не создавались товары под каждый цвет а просто 1 товар с вариантами этого цвета. 
3. Если при массовом заолнении товара цена или размер не указаны то заполнить эти поля значением "уточнить у продавца"
